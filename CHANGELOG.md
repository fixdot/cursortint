# Changelog

All notable changes to this project will be documented in this file.

## v0.1.2

- Improved cursor color updates for programmatic input-source changes (such as GumSyrup) by rechecking the input source after 10 ms.
- Reduced the risk of freezes when closing Terminal sessions by using nonblocking TTY access.

## v0.1.1

- Added support for ABC and ABC Extended input sources.
- About now shows the app version from the bundle.

## v0.1.0

- Initial release.
- Added input-source-based Terminal cursor color indication.
- Added menu bar controls for About and Quit.
